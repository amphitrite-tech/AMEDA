Purpose:
  Fits theoretical eddy velocity profile to observed streamline data
  
Model:
  V/Vmax = (R/Rmax) * exp((1 - (R/Rmax)^α) / α)
  
Key Features:
  ✓ Determines eddy degree α (α=2 for Gaussian)
  ✓ Computes R², RMSE, χ² error statistics
  ✓ Uses scipy.optimize.curve_fit for robust fitting
  ✓ Handles edge cases and insufficient data
